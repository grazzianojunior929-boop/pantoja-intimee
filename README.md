# Pantoja Intimeé · Moda Íntima Feminina

Site de vendas (versão de teste) da **Pantoja Intimeé** — Lingeries & Sex Shop, Aliança - TO.

- Site estático, um único arquivo: `index.html`
- Pedidos finalizados pelo WhatsApp
- Produtos, preços, WhatsApp e frete grátis são editados no início do `<script>` (bloco `CONFIGURAÇÕES — EDITE AQUI`)
- Fotos dos produtos ficam na pasta `img/`

Hospedado via GitHub Pages.
